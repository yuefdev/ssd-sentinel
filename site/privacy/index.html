Privacy Policy

Updated 28 November 2026 · Türkçe

Desktop data

SSD Sentinel runs without an account, advertising, analytics, or automatic crash reporting. Disk identifiers, SMART measurements, paths, recovery results, job history, and exported reports are handled locally. Exports and recovered files are saved to the destination you choose and may contain sensitive information.

The installed app stores its history and preferences under %LOCALAPPDATA%\com.ssdsentinel.desktop by default. The portable edition defaults to data beside the executable. Remove the installed app through Windows Settings → Apps. To remove retained local app data, close the app and delete its data folder. To remove the portable edition, disable its optional Windows startup entry if enabled, then remove the extracted folder. Save any reports or recovered files you want to keep before removing a folder.

Update checks and downloads

In live mode, SSD Sentinel checks GitHub Releases once at startup by default. The HTTPS request includes the SSD Sentinel version in the user-agent and the repository path. GitHub receives normal connection information such as your IP address. Update requests contain no disk identifiers, SMART data, file paths, or reports.

Turn off Check for updates automatically on startup in Tools & Settings to stop startup checks. You can still use Check for updates manually. Downloads start after confirmation and are checked against the release's SHA-256 manifest before use. Set the environment variable SSD_SENTINEL_UPDATE_REPO=none before starting the app to disable the built-in updater entirely.

GitHub hosts the website, release metadata, and downloads. See the GitHub Privacy Statement.

Third-party components and website

SSD Sentinel uses bundled smartctl.exe for local storage commands from smartmontools. The installer uses Microsoft's bootstrapper to download WebView2 if the runtime is missing. Microsoft handles its runtime and related services under the Microsoft Privacy Statement.

This website uses browser local storage to remember your theme. It has no project-operated analytics or advertising trackers. Follow-up questions about privacy can be directed to the project maintainer. Use the security reporting process for sensitive reports.

Gizlilik Politikası

SSD Sentinel hesap, reklam, analiz veya otomatik çökme raporu kullanmaz. Disk kimlikleri, SMART ölçümleri, dosya yolları, kurtarma sonuçları, işlem geçmişi ve raporlar cihazınızda işlenir. Dışa aktardığınız raporlar ve kurtardığınız dosyalar seçtiğiniz konuma kaydedilir ve hassas bilgiler içerebilir.

Kurulu sürüm geçmişi ve ayarları varsayılan olarak %LOCALAPPDATA%\com.ssdsentinel.desktop konumuna, taşınabilir sürüm ise uygulamanın yanındaki data klasörüne kaydeder. Kurulu sürümü Windows Ayarları → Uygulamalar bölümünden kaldırabilirsiniz. Kalan yerel verileri silmek için uygulamayı kapatıp veri klasörünü kaldırın. Taşınabilir sürümü kaldırmak için etkinse Windows açılış ayarını kapatın, ardından çıkardığınız klasörü silin. Saklamak istediğiniz dosyaları klasörü silmeden önce yedekleyin.

Canlı modda uygulama varsayılan olarak açılışta GitHub Releases'a bir HTTPS sorgusu gönderir. Sorgu uygulama sürümünü ve depo yolunu içerir. GitHub IP adresiniz gibi bağlantı bilgilerini görür. Disk kimlikleri, SMART bilgileri, yerel dosya yolları veya raporlar gönderilmez. Bakım ve Ayarlar → Açılışta otomatik güncelleme denetimi seçeneğini kapatabilirsiniz. Manuel kontrol çalışmaya devam eder. İndirme onayınızla başlar ve paket SHA-256 ile doğrulanır. Yerleşik güncelleyiciyi tamamen kapatmak için uygulamayı başlatmadan önce SSD_SENTINEL_UPDATE_REPO=none ortam değişkenini ayarlayın.

Disk sorguları için paketle gelen smartmontools yerel olarak çalışır. Kurucu, WebView2 eksikse Microsoft'tan indirir. Site teması tarayıcının yerel depolama alanında saklanır. Site ve sürümler GitHub, WebView2 ise Microsoft gizlilik politikası kapsamındadır.
