SSD Sentinel Frequently Asked Questions

Clear answers on capabilities, safety guarantees, comparisons, privacy, and verifying open-source releases.

What is the best free SSD health monitoring software for Windows 11?

The right choice depends on what you need: CrystalDiskInfo is great for minimal, signed SMART status viewing; vendor apps like Samsung Magician handle proprietary firmware updates; and SSD Sentinel is ideal if you want a free, MIT-licensed desktop suite combining SMART endurance forecasting, Win32 IOCP benchmarking, 200-zone LBA surface scanning, and read-only NTFS file recovery.

What are the best open-source CrystalDiskInfo alternatives?

SSD Sentinel (MIT, Rust + Tauri 2 GUI), smartmontools (GPLv2+ CLI/daemon), and GSmartControl (cross-platform GUI wrapper for smartctl). See our full CrystalDiskInfo comparison.

Is there a free alternative to Hard Disk Sentinel?

Yes — SSD Sentinel offers NVMe/SATA SMART diagnostics, SQLite wear forecasting, 200-zone raw LBA surface scanning with thermal/cascade watchdogs, and Win32 IOCP benchmarking under the MIT License without paid Pro paywalls. See our Hard Disk Sentinel comparison.

How can I check my NVMe SSD lifespan?

Open SSD Sentinel with Read-Only Guard locked and check Percentage Used, Available Spare, Data Units Written (TBW), and the local SQLite write-rate projection. Full steps in our NVMe Lifespan Guide.

What is Default Read-Only Guard?

Every fresh installation initializes read_only_guard = true in Rust (src-tauri/src/core.rs). Benchmarks, surface repairs, NTFS tier moves, developer workspace cleanups, and optimization tweaks fail closed at the IPC boundary until you unlock the guard and confirm a Dry-Run Execution Manifest.

Why does Windows SmartScreen warn about an Unknown Publisher?

Community installers are unsigned open-source builds (no paid EV Authenticode certificate). Always verify the installer against SHA256SUMS.txt or run gh attestation verify "SSD-Sentinel_1.10.1_x64-setup.exe" --owner yuefdev to verify GitHub's SLSA Build Provenance, or build locally from source.

Does SSD Sentinel collect telemetry or use AI/ML models on my drives?

No. SSD Sentinel contains zero analytics, zero cloud telemetry, and zero AI/ML models. Surface triage uses deterministic statistics and threshold rules (surface_triage.rs), and telemetry stays in %LOCALAPPDATA%\SSD Sentinel\history.sqlite3. Updates run only when you click Check for updates.

Can I test the UI without touching any physical disks?

Yes. Run .\ssd-sentinel.exe --snapshot-dir .\src-tauri\tests\fixtures to launch Snapshot Replay Mode against synthetic HDD + NVMe fixtures with zero physical storage writes or device probing.

How are MIT and GPLv2+ licenses separated?

SSD Sentinel's original Rust, TypeScript, CSS, SVG, and PowerShell source is MIT-licensed. Windows releases bundle upstream smartmontools 7.5 (smartctl.exe, GNU GPL-2.0-or-later) in a separate subdirectory with its matching RELEASE_7_5 source tarball published alongside every release.

Which Windows versions and languages are supported?

Windows 10 and Windows 11 (x64) with WebView2. Both the NSIS installer and application/tray UI automatically follow your Windows locale and support instant switching between English (EN) and Turkish (TR).
