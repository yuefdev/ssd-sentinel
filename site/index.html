What is SSD Sentinel? SSD Sentinel is a clean-room Windows 10/11 storage diagnostics and safety suite written in Rust and TypeScript. Designed as a free, open-source alternative to CrystalDiskInfo and Hard Disk Sentinel, it combines SMART health tracking, wear forecasting, raw Win32 IOCP benchmarking, 200-zone LBA surface diagnostics, SHA-256 NTFS Junction tiering, and strictly read-only forensic file recovery in a single ~3.7 MB installer.

Core Capabilities Built for Drive Safety

SMART & Endurance Forecasting

Reads live NVMe, SATA SSD, and HDD SMART counters via smartctl with per-disk fault isolation (read_incomplete). Logs up to 720 samples locally in SQLite to project daily write rates and remaining years.

Win32 IOCP Direct-I/O Benchmark

Measures true unbuffered storage throughput (SEQ & RND 4K MB/s, IOPS, µs latency) using FILE_FLAG_NO_BUFFERING | OVERLAPPED and checks PCIe/SATA link speeds for hardware bottlenecks.

200-Zone Surface Scan & Repair

Performs read-only raw LBA latency mapping with resumable checkpoints, a 53 °C thermal cooldown pause, a +8 reallocated sector cascade abort, and atomic FSCTL_MOVE_FILE cluster relocation.

Read-Only NTFS Recovery

Scans $MFT, $UsnJrnl, $I30 slack, VSS Shadow Copies, and file signatures strictly read-only, reconstructs deleted apps, and repairs JPEG/PNG/MP4 headers into a separate destination folder.

SHA-256 NTFS Storage Tiering

Blocks classic SSD defrag while offloading cold folders or developer/LLM caches across volumes using streaming SHA-256 verification and native FSCTL_SET_REPARSE_POINT junctions with one-click rollback.

Default Read-Only Write Guard

Every fresh install boots with read_only_guard = true in Rust. Benchmarks, surface repairs, tier moves, and policy changes stay locked until explicitly unlocked and confirmed via Dry-Run Execution Manifests.

Download SSD Sentinel for Windows

Get the x64 installer or portable ZIP for Windows 10 and 11 from the latest GitHub release. Windows Settings → Apps can remove the installed edition.

SSD Sentinel plans to use SignPath Foundation for code signing. See the Code signing policy and Privacy Policy.

The current Windows installer is unsigned. Windows may show an "Unknown Publisher" prompt. Compare your file's SHA-256 with SHA256SUMS.txt from the same release or verify its build provenance with GitHub CLI.

gh attestation verify "<downloaded-filename>" --repo yuefdev/ssd-sentinel

Want to explore the interface with zero physical disk access? Launch Snapshot Replay Mode against anonymized repo fixtures:

.\ssd-sentinel.exe --snapshot-dir .\src-tauri\tests\fixtures
