Safety Architecture Highlights

Disk surface tools and sector diagnostics carry genuine risk when implemented carelessly. SSD Sentinel documents every safety invariant openly in docs/SAFETY_SPEC.md:

  • Default Read-Only Guard: Fresh installs start locked (read_only_guard = true). Mutating operations fail closed in Rust until unlocked.
  • Thermal & Cascade Watchdogs: Physical LBA scans poll SMART every 60 seconds, pause at 53.0 °C to let drives cool, and immediately abort if reallocated sectors climb by 8 or more.
  • Atomic Cluster Relocation First: Pinpoint repair moves user files away from weak clusters via FSCTL_MOVE_FILE before running controlled refresh checks, and blocks bad-zone isolation and classic defrag on SSDs.
  • Crash-Safe Checkpoints: Full LBA surface scans checkpoint every 5 zones in local SQLite so interrupted runs resume cleanly.

Honest Trade-Offs to Know

Hard Disk Sentinel remains a strong commercial choice for multi-OS server fleets, hardware RAID array controllers, automated email/network SNMP alerting, and Windows environments requiring commercial Authenticode signatures. SSD Sentinel targets Windows 10/11 workstations and enthusiasts who want transparent MIT source code, modern UI ergonomics, built-in recovery and tiering, and zero paywalls.
