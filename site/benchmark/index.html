Free SSD & HDD Benchmark Tool for Windows (Win32 IOCP Direct-I/O)

Direct Answer: SSD Sentinel includes a free, open-source Win32 IOCP Direct-I/O disk benchmark directly alongside SMART monitoring. Using CreateFileW with FILE_FLAG_NO_BUFFERING | FILE_FLAG_OVERLAPPED and I/O Completion Ports, it measures sequential (SEQ) MB/s, random 4K (RND 4K) MB/s, IOPS, and microsecond (µs) latency while inspecting PCIe/SATA link speeds for hardware bottlenecks.

Why Unbuffered Direct-I/O Matters

Naive disk benchmarks that rely on ordinary buffered writes simply measure how quickly Windows copies data into system RAM (page cache). On a 32 GB desktop, cached runs can report multi-gigabyte speeds even on a slow SATA SSD or mechanical hard drive.

SSD Sentinel's Rust engine (jobs.rs) aligns I/O buffers directly against physical sector boundaries with FILE_FLAG_NO_BUFFERING and drives concurrent queue depth via Win32 I/O Completion Ports (IOCP), giving repeatable numbers closer to real storage controller behavior.

What the Benchmark Measures

Sequential Throughput (SEQ MB/s)

Tests sustained large-block read and write bandwidth — ideal for spotting SLC cache saturation or PCIe Gen 3 vs Gen 4 lane limits.

Random 4K IOPS & Latency (µs)

Measures small random 4 KB operations and microsecond response latency that directly govern OS boot, app launches, and build responsiveness.

PCIe / SATA Link Bottleneck Check

Read-only Windows SetupAPI/CfgMgr device tree queries inspect negotiated PCIe link width/generation so you immediately see if an M.2 slot fell back to x2 or Gen 2.

Write-Budget & Cancel Cleanup

Locked by Default Read-Only Guard until unlocked; displays target volume and write scope in a Dry-Run modal, and deletes its temporary test payload automatically if cancelled or dropped.

Benchmark Safety Guarantees

  • Existing user files remain untouched: Only an isolated temporary file inside the target volume root is created and removed on completion or cancellation.
  • Single-flight concurrency lock: Rust's Permit lock guarantees two benchmarks or disk jobs never contend on the same drive simultaneously.
  • Local SQLite history: Keeps up to 20 benchmark records locally so you can compare before/after firmware, BIOS M.2 slot, or write-cache policy changes.
