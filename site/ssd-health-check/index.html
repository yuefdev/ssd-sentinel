How to Check SSD Health on Windows 10 & Windows 11

Quick Summary: For a fast sanity check, use Windows Settings or PowerShell Get-PhysicalDisk. For full SMART error counters, NAND wear percentage, thermal tracking, PCIe link speed verification, and multi-month lifespan projections, use a dedicated open-source monitor like SSD Sentinel (which boots with Read-Only Guard enabled so nothing writes to your drive).

Step 1: Check Built-In Windows 11 Storage Properties

Windows 11 exposes basic NVMe health estimation natively without installing third-party software:

  1. Open Settings → System → Storage → Advanced storage settings → Disks & volumes.
  2. Expand your physical drive and click Properties.
  3. Inspect Estimated remaining life, Available spare, and Temperature if supported by the storage driver.

Limitation: Many SATA drives, dual-NVMe setups, and external USB enclosures hide detailed error logs or show incomplete metrics in the simplified Windows Settings view.

Step 2: Query Storage Reliability Counters in PowerShell

Open Windows Terminal or PowerShell (Administrator gives complete reliability counters across all buses) and run:

Get-PhysicalDisk | Select-Object FriendlyName, MediaType, HealthStatus, OperationalStatus, Size
Get-PhysicalDisk | Get-StorageReliabilityCounter | Select-Object DeviceId, Temperature, Wear, ReadErrorsUncorrected, WriteErrorsTotal

Healthy drives report HealthStatus : Healthy, Wear comfortably below 80–90, and 0 uncorrected read errors.

Step 3: Inspect Complete SMART Telemetry & Trends with SSD Sentinel

To inspect vendor-level SMART logs, PCIe link negotiation, and wear trends over time without risking accidental writes:

  1. Download and install SSD Sentinel (keep Write Guard locked in the top toolbar).
  2. Select your NVMe SSD, SATA SSD, or HDD in the Drive Overview to view live health %, temperature, power-on hours, and SMART logs queried via bundled smartctl.exe.
  3. Check the PCIe / SATA link status to confirm an NVMe PCIe 4.0 x4 SSD isn't silently running at x1 or Gen 2 speeds.
  4. Export a redacted HTML or JSON diagnostic report from the UI whenever you want a shareable snapshot for troubleshooting.

Warning Signs You Should Back Up Immediately

  • NVMe Critical Warning bitmask non-zero: Firmware has flagged spare depletion, thermal excursion, reliability degradation, or read-only mode.
  • Media and Data Integrity Errors > 0 (NVMe) or Reallocated / Pending Sectors climbing (SATA): Indicates unreadable NAND pages or failing blocks.
  • Available Spare dropping toward Available Spare Threshold: The drive's reserve flash pool is nearly exhausted.
  • Sustained temperatures above 70 °C under normal load: Drives thermal throttle first and accumulate retention errors faster under extreme heat.
